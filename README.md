# מַעֲרָךְ · מערכי שיעור לחט״ב ולתיכון

**לאתר:** https://lashon-lesson.github.io/maarach-lesson-plans/

מאגר אישי של מערכי שיעור לחטיבת הביניים ולתיכון, עם כמה כלים:

- **הספרייה:** מערכי שיעור לדוגמה במקצועות שונים, עם חיפוש וסינון לפי מקצוע, שכבה ומודל פדגוגי.
- **בונה המערכים:** בונים מערך לפי מודל פדגוגי (5E, אני-אנחנו-אתם, למידת חקר ועוד), עם איזון זמנים, הבחנה לשלוש רמות, שאלות לפי בלום, נושא בתוכנית הלימודים וקישורים למקורות.
- **מחולל חכם:** בונה טיוטת מערך מתוך נושא, שכבה ומשך השיעור.
- **בנק אסטרטגיות:** דרכי הוראה פעילות, שנכנסות למערך בלחיצה אחת.
- **מאגר ברשת:** קישורים לתוכניות הלימודים, למערכי שיעור וליחידות הוראה של משרד החינוך ומרכזי מורים, ונושאי תוכנית הלימודים לפי שכבה.
- **העברת שיעור:** מצגת עם טיימר, שולף שמות ומחלק קבוצות.

המערכים נשמרים בדפדפן (localStorage). כדי להעביר אותם בין מחשבים משתמשים ב"ייצוא" וב"ייבוא".
